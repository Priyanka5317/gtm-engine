Exists so the repo runs standalone. The real table this engine was built
against holds 534 rows over six months and is not published, because it
carries company names, recruiter identities and private notes. The engine
ships; the data does not.

The status column is deliberately messy in the same ways the real one is:
two languages, inconsistent casing, markdown bold left in, trailing
commentary, and a few values that map to nothing. That mess is the point.
